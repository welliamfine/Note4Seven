## 大文件策略

当前没有已配置的远程仓库和团队 LFS 配额，因此首个基线采用“受控外部归档 + SHA-256 清单”，避免把约 58 MB 的设计源文件和历史产物写入普通 Git 历史。远程设计存储的位置和访问负责人必须在仓库接入时补充到 `docs/governance/external-assets.json`，之后再通过 ADR 决定是否迁移到 Git LFS。

## 远程仓库门禁

当前只能建立本地 `main` 基线。远程管理员仍需完成：

1. 创建私有远程仓库并推送基线及带注释标签。
2. 将 `.github/CODEOWNERS` 的占位主体替换为真实账号或团队。
3. 禁止强推和删除默认分支，禁止直接提交。
4. 要求 CI 门禁全部通过且至少一名代码所有者审核。
5. 开启 Secret scanning、依赖告警和不可变发布制品策略。

完成上述操作前，不得把“本地存在 Git 历史”表述为“受保护远程仓库已就绪”。
