## 0. 背景与基线

当前回忆页会根据周期内的打卡记录，自动抽取贴纸并以固定位置展示在拼贴板上。用户只能更换一组贴纸，并通过现有按钮将自动生成的卡片保存到相册，无法表达自己的排版、装饰和主题选择。

本需求将“回忆拼贴”升级为可编辑的用户作品：

1. 用户可以在回忆页点击“编辑”进入独立编辑器；
2. 编辑器提供打卡贴纸、装饰贴纸和可更换画板；
3. 用户可以自由添加、移动、缩放、旋转和删除贴纸；
4. 点击“保存”后，作品布局持久化，回忆页展示保存后的完整画板；
5. 原有导出到系统相册能力保留，但不再占用回忆页主按钮。

本需求遵循项目既有约定：Figma 已展示的界面优先；业务事实由服务端维护；媒体使用私有对象存储和短期签名 URL；写操作支持 `clientRequestId` 幂等；业务日期按 `Asia/Shanghai` 计算。

## 1. 产品定义

### 1.1 产品目标

让用户在每个周报/月报周期内制作一张具有个人表达的回忆卡，并在之后反复查看、修改和导出。

### 1.2 用户价值

- 从“系统自动排版”变为“我来完成这张回忆”；
- 用装饰贴纸和画板主题增强记录的仪式感；
- 保存后的作品成为回忆页的稳定内容，不因每次重新抽取贴纸而改变；
- 仍可将最终作品导出到相册或分享给重要的人。

### 1.3 用户故事

> 作为回忆页用户，我希望选择一个喜欢的画板，放入本周期的打卡贴纸，再添加一些装饰贴纸并自由调整位置，保存后下次进入回忆页仍能看到我的作品。

### 1.4 成功指标

| 指标 | 定义 | 首版目标 |
|---|---|---:|
| 编辑入口点击率 | 回忆页访问用户点击“编辑”的比例 | ≥15% |
| 编辑保存率 | 进入编辑器后成功保存的比例 | ≥60% |
| 作品复访率 | 保存后 7 日内再次打开该作品的用户比例 | ≥30% |
| 装饰贴纸使用率 | 保存作品中至少有 1 个装饰贴纸的比例 | ≥40% |
| 保存成功率 | 点击保存后服务端成功且回忆页刷新正确的比例 | ≥99% |
| 导出成功率 | 点击导出到相册后保存成功的比例 | ≥95% |

指标只上报去标识化的数量、状态和耗时，不上报图片 URL、贴纸内容或作品文本。

## 2. 范围

### 2.1 本版本包含

- 回忆页拼贴板主按钮由“保存本月/本周回忆”改为“编辑”；
- 独立全屏回忆拼贴编辑器；
- 画板模板库和画板切换；
- 当前回忆周期打卡贴纸库；
- 装饰贴纸库、分类和横向分类栏；
- 点击添加、拖动、双指缩放、双指旋转；
- 选中、删除、复制添加、层级调整；
- 清空当前作品；
- 保存布局并返回回忆页；
- 保存后回忆页展示用户最后一次保存的作品；
- 编辑器内导出到相册；
- 失败重试、权限处理、未保存退出确认；
- 本地草稿保护和服务端版本冲突处理；
- 相关接口、数据库迁移、埋点和自动化测试。

### 2.2 本版本不包含

- 贴纸商城、付费购买、虚拟货币和订单；
- 用户上传自定义装饰贴纸；
- 文字输入、涂鸦、滤镜、背景音乐和视频；
- 多人同时在线编辑同一张作品；
- 公开作品广场；
- 作品历史版本浏览和回滚；
- 复杂的逐层时间线；
- 画板内直接编辑原始打卡记录；
- 自动抠图算法改造。

## 3. 核心概念与范围键

### 3.1 回忆作品

一份用户针对某个统计范围和周期保存的拼贴布局，包括画板、贴纸实例、位置、尺寸、角度和层级。

### 3.2 作品范围

作品必须绑定以下四个维度，避免不同周期和模块相互覆盖：

| 字段 | 可选值 | 说明 |
|---|---|---|
| `scopeKey` | `all` 或模块 ID | 全部模块或单个模块 |
| `reportMode` | `week`、`month` | 周报或月报 |
| `periodKey` | 月份或周一日期 | 例如 `2026-08`、`2026-08-03` |
| `userId` | 当前用户 | 作品属于创建者，不在成员间共享编辑权限 |

唯一业务键为 `userId + scopeKey + reportMode + periodKey`。同一范围每次保存覆盖当前版本，不产生历史版本。

### 3.3 资产类型

| 类型 | 说明 | 例子 |
|---|---|---|
| `record_sticker` | 用户本周期真实打卡生成的贴纸 | 人像、食物、宠物照片贴纸 |
| `decorative_sticker` | 产品提供的装饰资产 | 爱心、星星、日期章、胶带、花朵 |
| `board` | 作品底图模板 | 牛皮纸、白纸、相册纸、季节主题 |

## 4. 信息架构与页面流程

```text
回忆页
  └─ 点击“编辑”
       ↓
回忆拼贴编辑器
  ├─ 读取已保存作品
  ├─ 未保存作品：生成默认初始布局
  ├─ 选择画板
  ├─ 选择打卡贴纸 / 装饰贴纸
  ├─ 画布手势编辑
  ├─ 清空
  ├─ 保存 → 保存布局 → 返回回忆页并展示最终作品
  ├─ 导出 → 保存最终作品图片到相册
  └─ 关闭 → 无修改直接返回；有修改弹出退出确认
```

### 4.1 初次进入编辑器

1. 读取当前回忆范围的作品和资产目录；
2. 有已保存作品时，按服务端布局还原；
3. 无已保存作品时，使用当前自动抽取的打卡贴纸生成初始布局；
4. 初始布局不立即写入服务端，只有用户点击“保存”才成为正式作品；
5. 若当前周期没有打卡贴纸，画板仍可编辑和保存装饰贴纸。

### 4.2 再次进入编辑器

加载最后一次保存的画板、贴纸、坐标、角度和层级。新增打卡记录不会自动插入画布，只在“打卡贴纸”素材栏显示“未添加”，避免破坏用户已完成的构图。

### 4.3 保存后回忆页

- 回忆页优先展示用户保存的作品；
- 没有作品时展示系统默认拼贴；
- 作品加载失败时保留默认拼贴并显示轻量提示，不阻塞回忆统计；
- 周期、模块筛选或周报/月报切换后，按新的范围读取对应作品；
- “编辑”按钮保持可用；
- 回忆页不允许直接拖动贴纸，所有编辑统一进入编辑器。

## 5. 页面与交互需求

### 5.1 回忆页拼贴模块

| 项目 | 需求 |
|---|---|
| 主按钮文案 | 有作品和无作品均显示“编辑” |
| 主按钮动作 | 打开当前 `scopeKey + reportMode + periodKey` 的编辑器 |
| 预览画板 | 展示保存后的画板和所有已保存贴纸，保持层级和角度 |
| 预览比例 | 使用固定作品比例，缩放适配屏幕，不因贴纸数量改变高度 |
| 加载态 | 画板底图先显示，贴纸逐步加载；失败资产使用占位 |
| 空态 | 无打卡、无装饰时显示“开始装饰这段回忆”与“编辑”按钮 |
| 兼容 | 周报和月报共用组件，但作品按范围隔离 |

### 5.2 编辑器整体布局

编辑器为全屏页面，适配刘海屏和底部安全区。

```text
┌────────────────────────────┐
│  关闭       2026年8月回忆   导出 │
│                              │
│        可交互回忆画板         │
│   贴纸可移动、缩放、旋转、删除  │
│                              │
│  清空                  保存   │
├────────────────────────────┤
│  画板  记录贴纸  装饰贴纸 ...  │  ← 分类栏
│  ──────────────────────────  │
│  资产缩略图横向/网格列表       │  ← 资产选择栏
└────────────────────────────┘
```

#### 顶部栏

- 左侧：关闭按钮；
- 中间：周期标题，例如“2026年8月回忆”；
- 右侧：导出图标按钮，执行保存到相册；
- 顶部不显示与作品无关的统计指标；
- 返回时系统返回键与关闭按钮行为一致。

#### 画板区

- 画板位于页面中上部，占可用高度约 52%～58%；
- 画板使用固定宽高比，默认 `1:1`，不同模板必须保持同一导出比例；
- 画板底图覆盖整个画布，不允许拖出画布边界；
- 画布上的贴纸是独立可选图层；
- 未选中时不显示控制框；
- 选中时显示轻量边界框、删除按钮和旋转/缩放控制点；
- 点击空白区域取消选中。

#### 底部资产区

- 第一行是可横向滑动的资产类型：画板、打卡贴纸、装饰贴纸；
- 装饰贴纸下可按分类筛选：全部、表情、边框、胶带、印章、节日；
- 第二行是缩略图网格，推荐 4 列，卡片固定高度；
- 点击资产即添加一个新实例，不替换当前选中实例；
- 已添加的装饰贴纸仍可再次点击添加多个实例；
- 已添加的打卡贴纸显示选中标记，重复添加仍允许，最多受数量上限限制；
- 资产加载失败显示占位和重试入口；
- 资产栏滚动不影响画板内贴纸手势。

#### 操作栏

- “清空”：清除当前画布中的全部贴纸，画板底图保留；
- “保存”：保存画板、贴纸和布局，成功后返回回忆页；
- 有未保存修改时关闭或系统返回弹出确认：继续编辑、放弃修改；
- 保存中禁止重复提交，显示加载状态；
- 保存失败保留编辑状态，允许重试。

### 5.3 画板切换

1. 点击“画板”进入画板选择栏；
2. 展示可用画板缩略图、名称和主题标签；
3. 点击新画板立即在当前编辑器预览；
4. 切换画板不删除已有贴纸、不改变贴纸位置和层级；
5. 保存后新画板成为该作品的底图；
6. 画板资产下架后，已保存作品仍必须可以渲染，直到作品被用户另存为其他画板；
7. 不同画板统一导出尺寸和安全边距。

### 5.4 贴纸操作

| 操作 | 触发 | 结果 |
|---|---|---|
| 添加 | 点击资产缩略图 | 在画板中心偏移位置新增实例并选中 |
| 移动 | 单指拖动选中贴纸 | 更新 `x/y`，限制在画板可见区域 |
| 缩放 | 双指捏合或控制点拖动 | 更新 `width/height`，保持最小/最大尺寸 |
| 旋转 | 双指旋转或旋转控制点 | 更新 `rotation`，范围 `-180°`～`180°` |
| 删除 | 选中后点击删除按钮 | 移除实例并选中相邻图层 |
| 置顶 | 双击或控制菜单“置顶” | 设置最高 `zIndex` |
| 置底 | 控制菜单“置底” | 设置最低 `zIndex` |
| 取消选择 | 点击画板空白处 | 隐藏控制框 |

贴纸变换坐标使用归一化坐标，范围为 `0`～`1`，与设备屏幕尺寸无关。服务端保存中心点、尺寸、角度和层级，前端按实际画板尺寸还原。

### 5.5 清空

- 画板底图不清除；
- 无贴纸时按钮置灰；
- 有贴纸时点击弹出确认：“清空后需要重新添加贴纸，确定清空吗？”；
- 确认后立即清除本地编辑状态并标记为未保存；
- 清空不直接删除服务端正式作品，用户点击“保存”后才覆盖为清空作品；
- 放弃退出时，恢复进入编辑器前的正式作品。

### 5.6 保存

保存操作采用“完整快照替换”：一次请求提交当前画板和全部图层，服务端事务内校验并替换作品内容。

- 保存前校验画板存在、贴纸资产仍可用、图层数量和坐标合法；
- 保存成功后返回作品版本号；
- 返回回忆页后主动刷新预览，不依赖页面缓存；
- 保存成功事件与导出相册事件分开统计；
- 用户点击顶部“导出”时，导出当前未保存布局，并提示“导出不会自动保存作品”；
- 用户也可以先保存再导出，导出内容必须与当前编辑器画面一致。

### 5.7 未保存退出

以下任一条件满足即视为有未保存修改：

- 添加或删除图层；
- 移动、缩放或旋转图层；
- 切换画板；
- 清空图层。

确认弹窗提供：

- “继续编辑”：关闭弹窗；
- “放弃修改”：丢弃本地状态并返回；
- 不提供自动保存，避免用户误把半成品设为正式作品。

## 6. 默认布局与数量规则

### 6.1 默认布局

首次进入且存在打卡贴纸时：

- 最多自动放入 8 个本周期打卡贴纸；
- 按当前自动抽取顺序生成 2×4 的初始布局；
- 每个实例有轻微角度差，避免完全规整；
- 装饰贴纸不自动添加；
- 用户保存后，默认布局转为正式可编辑作品。

首次进入且没有打卡贴纸时，显示空画板。

### 6.2 上限与边界

| 规则 | 首版值 |
|---|---:|
| 单个作品最大图层数 | 40 |
| 其中打卡贴纸最大数 | 8 |
| 单个装饰贴纸最大重复数 | 10 |
| 贴纸最小宽度 | 画板宽度的 8% |
| 贴纸最大宽度 | 画板宽度的 70% |
| 允许越界 | 不允许主体完全离开画板；允许最多 20% 边缘出血 |
| 层级范围 | 0～999 |

达到上限时提示“画板已经很丰富了”，不再新增。

## 7. 资产库需求

### 7.1 画板库

画板资产至少包含：

- `boardAssetId`；
- 名称、分类、缩略图、底图文件；
- 导出宽高和安全边距；
- 排序权重；
- `active`/`retired` 状态；
- 创建和更新时间。

首版建议提供 6～10 张画板：牛皮纸、白纸、拍立得、网格纸、浅色布纹和 2～4 张季节主题。项目现有牛皮纸画板作为默认画板，不能删除。

### 7.2 装饰贴纸库

首版建议提供 30～50 个装饰贴纸，覆盖以下分类：

- 表情与符号：爱心、星星、笑脸、惊叹号；
- 胶带与边框：纸胶带、胶片框、便签；
- 印章与日期：本月、完成、今日、纪念日；
- 生活元素：咖啡、面包、花朵、云朵、礼物；
- 节日主题：按节日可配置上下架。

每个资产必须提供透明 PNG/WebP 原图和缩略图，禁止使用不可控外链。

### 7.3 资产版本与下架

- 资产使用稳定 ID，不以文件路径作为业务主键；
- 下架只影响新添加，不影响已保存作品的渲染；
- 替换文件时保留旧文件版本，直至没有作品引用；
- 资产目录支持缓存，签名 URL 过期后可刷新；
- 首版资产由配置/种子管理，不提供运营后台。

| `version` | int | 乐观锁版本 |
| `status` | enum | `active`、`deleted` |
| `created_at` / `updated_at` / `saved_at` | datetime | 时间字段 |

唯一索引：`user_id, scope_key, report_mode, period_key`。

### 8.4 `memory_collage_item`

| 字段 | 类型 | 说明 |
|---|---|---|
| `item_id` | ID | 主键 |
| `collage_id` | ID | 所属作品 |
| `asset_type` | enum | `record_sticker`、`decorative_sticker` |
| `record_id` | ID/null | 打卡贴纸引用 |
| `sticker_asset_id` | ID/null | 装饰贴纸引用 |
| `x` / `y` | decimal | 归一化中心坐标 |
| `width` / `height` | decimal | 归一化尺寸 |
| `rotation` | decimal | 角度，单位度 |
| `z_index` | int | 图层顺序 |
| `created_at` / `updated_at` | datetime | 时间字段 |

约束：`asset_type` 与引用字段必须匹配；同一 `collage_id` 下 `z_index` 不重复；所有归一化数据和角度必须经过服务端范围校验。

### 8.5 删除和一致性

- 用户删除作品时软删除 `memory_collage`，图层随作品不可见；
- 模块进入 `pending_delete` 或用户失去模块权限时，单模块作品只读或不可见；
- 打卡记录删除后，引用该记录的作品图层标记不可用，回忆页不阻塞加载；
- 装饰资产下架后，已引用图层仍使用旧版本文件；
- 周期删除不影响其他周期作品。

## 9. 接口需求

所有接口均需要鉴权，错误响应沿用项目统一格式，写接口需要 `clientRequestId`。

### 9.1 获取作品

`GET /memories/collage?scopeKey=all&mode=month&period=2026-08`

返回：

```json
{
  "collage": {
    "collageId": "mc_xxx",
    "scopeKey": "all",
    "reportMode": "month",
    "periodKey": "2026-08",
    "board": { "boardAssetId": "board_kraft", "imageUrl": "..." },
    "version": 3,
    "items": [
      {
        "itemId": "mci_xxx",
        "assetType": "decorative_sticker",
        "assetId": "sticker_heart",
        "imageUrl": "...",
        "x": 0.52,
        "y": 0.35,
        "width": 0.18,
        "height": 0.18,
        "rotation": -8,
        "zIndex": 4
      }
    ]
  },
  "availableRecordStickers": [],
  "boards": [],
  "decorativeStickerCategories": [],
  "decorativeStickers": []
}
```

无作品时 `collage` 为 `null`，但仍返回资产目录和当前周期可用的打卡贴纸。

### 9.2 保存作品

`PUT /memories/collage`

请求核心字段：

```json
{
  "clientRequestId": "req_xxx",
  "scopeKey": "all",
  "moduleId": null,
  "reportMode": "month",
  "periodKey": "2026-08",
  "boardAssetId": "board_kraft",
  "baseVersion": 3,
  "items": [
    {
      "assetType": "record_sticker",
      "recordId": "record_xxx",
      "x": 0.30,
      "y": 0.40,
      "width": 0.22,
      "height": 0.22,
      "rotation": 5,
      "zIndex": 1
    }
  ]
}
```

规则：

- `baseVersion` 不匹配时返回 `COLLAGE_VERSION_CONFLICT`，客户端提示用户重新加载或覆盖；
- 默认采用“重新加载并保留本地草稿”，不静默覆盖他人或其他设备的最新保存；
- 服务端在同一事务内校验范围权限、资产状态、记录归属、数量和坐标，再替换图层；
- 相同 `clientRequestId` 重放返回相同结果；
- 保存成功返回完整作品和新版本号。

### 9.3 清空作品

`PUT /memories/collage/clear`

请求包含范围键、`baseVersion` 和 `clientRequestId`。清空只删除图层，保留当前画板；若用户从未保存过作品，可以不发请求，仅在本地清空。

### 9.4 资产目录

可由获取作品接口一次返回，也可拆分为：

- `GET /memories/collage/boards`；
- `GET /memories/collage/stickers?category=all`。

资产返回短期签名 URL，客户端不得永久保存签名 URL。

### 9.5 导出相册

沿用现有 Canvas 导出方案。导出接口不写业务数据，客户端直接使用当前编辑器状态生成临时文件并调用微信相册权限。导出失败不影响已保存作品。

## 10. 状态机

### 10.1 作品状态

```text
no_saved_collage
  └─ open_editor → local_draft

local_draft
  ├─ edit → dirty_draft
  ├─ save_success → saved_collage
  └─ abandon → no_saved_collage

saved_collage
  └─ open_editor → local_draft

dirty_draft
  ├─ save_success → saved_collage
  ├─ save_conflict → conflict
  └─ abandon → saved_collage

conflict
  ├─ reload_latest → local_draft
  └─ overwrite_after_confirm → saved_collage
```

### 10.2 编辑器临时状态

| 状态 | 说明 |
|---|---|
| `loading` | 读取作品和资产 |
| `ready` | 可编辑 |
| `dirty` | 有未保存变化 |
| `saving` | 保存请求中 |
| `exporting` | 生成相册图片 |
| `error` | 可恢复错误，不清空本地草稿 |
| `closed` | 离开编辑器 |

## 11. 权限与安全

- 只有当前用户可以修改自己的作品；
- 单模块作品必须校验当前用户仍是有效成员；
- `record_sticker` 只能引用当前用户有权限查看的正式记录；
- 资产文件走短期签名 URL；
- 服务端不能信任客户端传入的图片路径、模块 ID 或记录归属；
- 作品保存不包含备注、原图地址、成员隐私字段；
- 导出图片只包含用户当前画板内容，不自动加入统计数据，除非产品后续明确配置；
- 记录、模块或资产被删除/下架时，按一致性规则处理引用，不返回越权数据。

## 13. 验收标准

### 13.1 功能验收

1. 回忆页主按钮文案为“编辑”，点击进入正确的作品范围；
2. 已保存作品再次进入时，画板、贴纸、位置、尺寸、角度和层级完全恢复；
3. 可以切换画板，切换不会删除贴纸；
4. 可以添加打卡贴纸和装饰贴纸，装饰贴纸可重复添加；
5. 贴纸支持移动、缩放、旋转、删除，不能完全拖出画板；
6. 清空只清除贴纸，不清除画板；放弃退出不影响已保存作品；
7. 保存后返回回忆页，预览立即显示最终画板；刷新页面后仍然显示；
8. 周报、月报、全部模块和单模块作品互不覆盖；
9. 新增打卡记录显示在素材栏，不破坏已有构图；
10. 删除记录或失去模块权限后，不发生越权，作品仍可恢复或显示占位；
11. 导出相册生成的图片与当前编辑器画面一致；
12. 无网络、签名 URL 过期、相册权限拒绝和保存冲突均有可理解的恢复路径。

### 13.2 视觉验收

- 编辑器整体延续回忆页材质、圆角、字体和颜色；
- 画板是页面视觉主体，底部资产区不遮挡画板操作按钮；
- 资产缩略图固定尺寸，不因图片比例导致网格跳动；
- 选中框、删除按钮和旋转控制点在小屏设备上不互相遮挡；
- 全面屏、底部手势区和横向资产滚动正常；
- 画板切换、贴纸添加和保存有轻量动效，支持减少动态效果设置。

### 13.3 性能验收

- 已保存作品首屏骨架在 1 秒内出现；
- 画板和首批资产在弱网下可逐步加载；
- 编辑器同时显示 40 个图层时拖动仍保持可用；
- 保存接口 P95 小于 1.5 秒，不包含媒体下载；
- 导出 1800×1800 图片在主流真机上 P95 小于 5 秒；
- 资产缩略图采用分页/懒加载和缓存，避免一次下载全部原图。

## 16. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 小程序多指手势在不同机型表现不一致 | 高 | 先做真机 PoC；保留控制点操作作为替代路径 |
| 图层过多导致渲染卡顿 | 中 | 限制 40 层、缩略图懒加载、导出时统一 Canvas 合成 |
| 签名 URL 过期 | 中 | 资产以 ID 存储，加载失败自动刷新 URL |
| 记录被删除导致作品缺图 | 中 | 图层返回占位，允许用户删除或替换，不阻塞作品展示 |
| 多设备同时编辑 | 中 | `version` 乐观锁和冲突确认，不静默覆盖 |
| 画板资源侵权或风格不一致 | 中 | 资产登记、版权确认、统一透明素材规范 |
| 用户误把半成品保存 | 中 | 未保存退出确认，保存操作明确反馈 |
| 编辑器与首页/回忆页重复实现 | 中 | 独立编辑器页面，共用作品模型、导出工具和预览组件 |

## 17. 待评审决策

以下事项在设计和开发前必须确认：

1. “保存”是否只保存作品，还是保存后同时自动导出到相册；本 PRD 默认二者分离；
2. 是否允许在作品中添加文字；本版本默认不做；
3. 首版画板数量、装饰贴纸数量及视觉风格；
4. 装饰贴纸是否按节日自动上下架；
5. 清空后保存空画板时，回忆页是否显示纯画板；本 PRD 默认显示纯画板；
6. 作品是否允许成员查看；本 PRD 默认作品属于当前用户，回忆页仅当前用户可见；
7. 是否需要“分享作品”入口；本版本保留导出能力，不新增公开分享链路。
