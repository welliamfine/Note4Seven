# 前端字体统一规范 v2.1

## 1. 适用范围

本规范适用于全部小程序页面、弹窗、底部卡片、Tab 栏和表单组件。

特殊保留区域：

- 月历日期数字、周几和月历月份继续使用原有字色。
- 日历页月度数据概览和回忆页周数据概览继续使用原有字色。
- 回忆页 `RECORD` 卡片的字体、字号、字重、字色和行高均保持不变。
- 自定义 Tab 栏保留原有 `20rpx / 400 / 1` 字体组合和原有状态色。
- NoteMyLife 品牌标识、头像字符和装饰符号不纳入普通文字规范。

## 2. 字体家族

| Token | 字体 | 使用范围 |
|---|---|---|
| `--font-family-base` | 系统无衬线字体 | 标题、正文、按钮、导航和输入框 |
| `--font-family-brand` | Brush Script / Segoe Script | 仅 NoteMyLife 品牌文字 |
| `--font-family-data` | Georgia / Times New Roman | 月份和数据数字 |

系统字体栈：

```css
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif
```

## 3. 五级字号

项目只允许以下五档业务文字字号：

| 等级 | Token | 字号 | 默认行高 | 使用范围 |
|---|---|---:|---:|---|
| Caption | `--font-size-caption` | `20rpx` | `1.5` | Tab、时间、状态、角标 |
| Secondary | `--font-size-secondary` | `24rpx` | `1.5` | 摘要、说明、输入框、次级按钮 |
| Body | `--font-size-body` | `28rpx` | `1.5` | 正文、菜单、主要按钮、列表 |
| Title | `--font-size-title` | `32rpx` | `1.25` | 模块名、弹窗标题、二级页标题、关键数字 |
| Page Title | `--font-size-page-title` | `36rpx` | `1.25` | 一级页面标题 |

禁止新增其他业务文字字号。Emoji、头像字符和装饰符号按图形内容处理。

## 4. 字重

当前所有界面文字统一为：

```css
--font-weight-regular: 400;
```

标题、正文、按钮、Tab、数字、输入框和占位文字均使用 `400`。当前禁止使用 `500`、`600`、`bold` 和 `bolder`。

只有产品后续明确指定某个元素使用 `500` 时，才允许增加局部特殊样式；不得自行恢复某一整类标题的 `500` 字重。

## 5. 字色

### 默认字色

```css
--text-color-primary: #514b45;
```

页面标题、模块标题、正文、真实输入内容、菜单、普通按钮、Tab、昵称和普通数字统一使用默认字色。

### 浅色字

```css
--text-color-muted: #999188;
```

占位文字、摘要、时间、状态、禁用文字、空状态和无数据说明统一使用浅色字。

### 功能色

- 危险操作：`--signal-red: #F65451`。
- 反白文字：`#fff`，仅用于实色功能按钮、徽标或深色背景。
- 品牌色和特殊保留区域继续使用各自原色。

## 6. 行高

| Token | 数值 | 使用范围 |
|---|---:|---|
| `--line-height-tight` | `1.25` | 单行标题和数字 |
| `--line-height-normal` | `1.5` | 正文、按钮、菜单和输入内容 |
| `--line-height-relaxed` | `1.7` | 多行说明和长文本 |

固定高度按钮必须通过 Flex 或 Grid 垂直居中，不使用与按钮高度相等的行高。

## 7. 标准组合

| 场景 | 字号 | 字重 | 字色 | 行高 |
|---|---:|---:|---|---:|
| 一级页面标题 | `36rpx` | `400` | `#514b45` | `1.25` |
| 二级页/弹窗标题 | `32rpx` | `400` | `#514b45` | `1.25` |
| 模块名称 | `32rpx` | `400` | `#514b45` | `1.25` |
| 菜单、正文、主要按钮 | `28rpx` | `400` | `#514b45` | `1.5` |
| 输入内容 | `24rpx` | `400` | `#514b45` | `1.5` |
| 摘要和占位文字 | `24rpx` | `400` | `#999188` | `1.5` |
| Tab、时间和状态 | `20rpx` | `400` | 按语义选默认或浅色 | `1.5` |

## 8. 实施要求

- 页面优先使用全局 Token，禁止新增私有字号、字重和通用字色。
- `button`、`input`、`textarea` 必须显式继承全局字体和 `400` 字重。
- 输入组件必须通过 `placeholder-class="text-placeholder"` 使用统一占位色。
- 除保留区域和功能色外，通用文字只能使用 `#514b45` 或 `#999188`。
- 字间距统一为 `0`，不得依赖微信原生组件默认字体样式。
