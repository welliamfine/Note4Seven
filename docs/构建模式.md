# 小程序构建模式

构建模式必须通过以下命令明确选择。默认开发使用本地 Mock；真实云联调和发布构建必须使用显式命令，避免把不同环境混在一起。

## 云托管联调

持续监听源码变化，并让微信开发者工具连接 production 环境 `prod-d5g4tznceeecbaf39` 中的 `express-bonj` 服务：

```powershell
npm run dev:cloud
```

默认本地 Mock 命令：

```powershell
npm run dev
```

独立 staging 尚未配置，以下命令会明确失败，直到将隔离资源写入配置：

```powershell
npm run build:staging
```

单次 production 构建：

```powershell
npm run build:production
```

## 本地模式

使用内存/本地适配器 Mock：

```powershell
npm run dev:mock
```

使用本机 Express 后端和 Docker MySQL：

```powershell
npm run dev:local-backend
```

底层 `scripts/build.mjs` 不允许省略 `--api-mode`。构建开始时终端会显示实际模式，生产云模式应显示：

```text
[build] API mode: WeChat CloudRun (remote), environment: production
```
