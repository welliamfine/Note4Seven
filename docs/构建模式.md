# 小程序构建模式

构建模式必须通过以下命令明确选择。默认开发和默认构建均连接微信云托管，避免误生成本地 Mock 版本。

## 云托管联调

持续监听源码变化，并让微信开发者工具连接 `prod-d5g4tznceeecbaf39` 环境中的 `express-bonj` 服务：

```powershell
npm run dev
```

等价的显式命令：

```powershell
npm run dev:cloud
```

单次生产构建：

```powershell
npm run build
```

等价的显式命令：

```powershell
npm run build:production
```

## 本地模式

使用内存/本地适配器 Mock：

```powershell
npm run dev:mock
```

使用本机 Express 后端和 Docker MySQL：

```powershell
npm run dev:local-backend
```

底层 `scripts/build.mjs` 不允许省略 `--api-mode`。构建开始时终端会显示实际模式，生产云模式应显示：

```text
[build] API mode: WeChat CloudRun (remote)
```
