# 记录我的一辈子｜接口文档 V1.1（Figma统一对齐版）

> 依据：PRD V6.4、页面流程 V6.4、数据库设计 V1.1、状态机 V1.1。  
> 范围：微信小程序MVP，纯照片打卡、无模块头像。  
> 原型优先级：Figma已展示页面需要的数据结构以本接口为直接契约；未展示功能按PRD补齐。

---

## 1. 全局规范

### 1.1 Base URL

```text
/api/v1
```

### 1.2 鉴权

除登录、邀请公开预览外，均携带：

```http
Authorization: Bearer <accessToken>
```

服务端不得根据前端按钮是否显示判断权限。

### 1.3 统一响应

成功：

```json
{
  "code": "OK",
  "message": "success",
  "data": {},
  "requestId": "srv_req_xxx",
  "serverTime": "2026-07-15T12:00:00+08:00"
}
```

失败：

```json
{
  "code": "RECORD_ALREADY_EXISTS",
  "message": "今天已经有一条记录",
  "data": {
    "refreshRequired": true
  },
  "requestId": "srv_req_xxx",
  "serverTime": "2026-07-15T12:00:00+08:00"
}
```

### 1.4 幂等

所有写接口必须传 `clientRequestId`，可放请求体或 `Idempotency-Key` 请求头。规则：

- 同一用户、同一操作类型、同一 `clientRequestId` 只执行一次；
- 相同幂等键但请求体不同返回 `IDEMPOTENCY_CONFLICT`；
- 客户端超时后使用相同键重试，返回第一次结果；
- 创建记录、编辑记录、审批、创建模块、加入申请和成员操作均适用。

### 1.5 字段命名

统一使用 lowerCamelCase：

- `remark`：可选备注；不使用 `note`；
- `memberInstanceId`：成员关系实例；
- `joinSequence`：加入顺序；
- `firstEffectiveAt`：记录首次正式生效时间；
- `stickerThumbnailUrl`：短期签名贴纸缩略图URL；
- `availableActions`：当前用户可执行动作。

模块对象不得包含：

```text
moduleAvatar
moduleIcon
recordType
defaultStatusIcon
```

邀请页和成员管理页的叶子为客户端固定装饰，不由接口返回。

### 1.6 分页

游标分页：

```json
{
  "items": [],
  "nextCursor": "opaque_cursor",
  "hasMore": false
}
```

默认 `pageSize=20`，最大50。

### 1.7 时间与日期

- 时间：ISO 8601，带时区；
- 业务日期：`YYYY-MM-DD`；
- 月份：`YYYY-MM`；
- 所有日期权限以服务端 `Asia/Shanghai` 为准。

### 1.8 文件URL

原图、缩略图和贴纸均为私有资源，接口返回短期签名URL及过期时间：

```json
{
  "url": "https://signed.example/...",
  "urlExpireAt": "2026-07-15T12:10:00+08:00"
}
```

# 4. 模板与创建模块

## 4.1 获取创建模板

```http
GET /module-templates
```

返回：

```json
{
  "items": [
    {
      "templateId": "tpl_drink",
      "displayName": "摄入饮品中...",
```

```json

  "mode": "solo",
  "status": "active",

    "memberInstanceId": "mi_1",
```

```json

  "isPinned": true,
  "lastActivityAt": "2026-07-15T11:30:00+08:00",
```

- 编辑不改变排序，删除后重新打卡产生新的 `firstEffectiveAt`；
- 首页成员头像按 `joinSequence`。

# 9. 今日记录

## 9.1 创建今日记录

```http
POST /modules/{moduleId}/records
```

请求：

```json
{
  "recordDate": "2026-07-15",
  "mediaId": "media_1",
  "remark": "今天发生了什么小事",
  "clientRequestId": "uuid"
}
```

服务端校验：

- 日期必须为D0；
- 模块和成员均active；
- 媒体status=ready且cutoutStatus=succeeded；
- 同成员同日无有效记录。

## 9.2 获取单条记录

```http
GET /records/{recordId}
```

## 9.3 编辑今日记录

```http
PATCH /records/{recordId}
```

请求：

```json
{
  "mediaId": "media_2",
  "remark": "修改后的备注",
  "version": 2,
  "clientRequestId": "uuid"
}
```

编辑不改变 `firstEffectiveAt`。

## 9.4 删除今日记录

```http
DELETE /records/{recordId}
```

请求体：

```json
{
  "version": 3,
  "clientRequestId": "uuid"
}
```

删除后允许重新创建新Record。

# 20. 错误码

| 错误码 | HTTP | 含义 | 前端处理 |
|---|---:|---|---|
| `UNAUTHORIZED` | 401 | 未登录或会话失效 | 跳登录 |
| `NO_MODULE_PERMISSION` | 403 | 无模块权限 | 返回并提示 |
| `MODULE_NOT_FOUND` | 404 | 模块不存在 | 关闭目标页 |
| `MODULE_PENDING_DELETE` | 409 | 模块在回收期 | 进入恢复/删除提示 |
| `MODULE_DELETED` | 410 | 已永久删除 | 返回首页 |
| `MODULE_MEMBER_LIMIT_REACHED` | 409 | 已满4人 | 刷新人数 |
| `CREATOR_CANNOT_LEAVE` | 409 | 创建者不能直接退出 | 提示转让或删除 |
| `MEDIA_NOT_FOUND` | 404 | 媒体不存在 | 重新选择 |
| `MEDIA_NOT_READY` | 409 | 图片或贴纸未就绪 | 继续轮询 |
| `MEDIA_UPLOAD_FAILED` | 422 | 上传失败 | 重试或换图 |
| `CUTOUT_PROCESS_FAILED` | 422 | 抠图失败 | 重试或换图 |
| `IMAGE_CONTENT_REJECTED` | 422 | 内容安全未通过 | 重新选择 |
| `RECORD_ALREADY_EXISTS` | 409 | 同日已有有效记录 | 刷新详情 |
| `RECORD_LOCKED` | 409 | 历史记录锁定 | 转只读 |
| `RECORD_DATE_NOT_ALLOWED` | 422 | 日期不可操作 | 刷新serverTime |
| `MAKEUP_DATE_EXPIRED` | 422 | 超过D-3 | 只读 |
| `MAKEUP_ALREADY_PENDING` | 409 | 已有待审批申请 | 打开申请详情 |
| `APPROVAL_ALREADY_RESOLVED` | 409 | 审批已处理 | 刷新卡片 |
| `INVITE_EXPIRED` | 410 | Token过期 | 提示重新邀请 |
| `INVITE_REVOKED` | 410 | Token撤销 | 提示失效 |
| `JOIN_APPLICATION_ALREADY_PENDING` | 409 | 已有待处理申请 | 打开状态 |
| `JOIN_REAPPLY_COOLDOWN` | 429 | 被拒后24小时限制 | 展示可重试时间 |
| `JOIN_APPLICATION_ALREADY_RESOLVED` | 409 | 申请已处理 | 刷新 |
| `REACTION_SELF_NOT_ALLOWED` | 422 | 不能回应自己 | 不提交 |
| `IDEMPOTENCY_CONFLICT` | 409 | 幂等键请求不一致 | 生成新键前先核对 |
| `VERSION_CONFLICT` | 409 | 乐观锁冲突 | 刷新数据 |
| `RATE_LIMITED` | 429 | 频率限制 | 稍后重试 |

# 21. 接口验收

- [ ] 首页接口不返回模块头像、模块图标或记录类型；
- [ ] 首页贴纸最多4项，按firstEffectiveAt升序；
- [ ] 月历接口返回layoutSlot；
- [ ] 双人layoutSlot为top_center和bottom_center；
- [ ] 日期详情对未来日期返回只读面板数据；
- [ ] 创建/编辑记录统一使用remark；
- [ ] 媒体ready前无法创建正式记录；
- [ ] 编辑照片不改变firstEffectiveAt；
- [ ] 成员管理返回今日记录状态和可用动作；
- [ ] 邀请接口不返回装饰叶子业务字段；
- [ ] 通知加入审批支持卡片内原子操作；
- [ ] 所有写接口支持clientRequestId；
- [ ] 所有权限均由服务端验证。
