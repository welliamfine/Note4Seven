# ADR-0001：使用 OpenAPI 3.1 管理 HTTP 契约

- 状态：已接受
- 日期：2026-07-25

## 决策

采用 OpenAPI 3.1 作为机器可读 HTTP 契约。路由方法与路径从 TypeScript Express 源码解析生成，共享错误信封、公共 ID、时间、登录、媒体预创建和 COS 回调 Schema 在同一生成器中维护。CI 执行 `npm run openapi:check`，契约输出与源码不一致时阻止合并。

## 原因

OpenAPI 可被文档、契约测试和客户端代码生成工具共同消费，且 3.1 的 JSON Schema 语义适合表达当前 Zod 规则。当前阶段先保证完整路由清单和关键领域 Schema；其他请求/响应 Schema 按领域增量补充。

## 边界

生成器不能证明运行时响应一定满足 Schema，真实 MySQL 路由契约测试仍是后续门禁。任何破坏性修改必须提供版本或旧客户端兼容窗口，示例只允许合成数据。
