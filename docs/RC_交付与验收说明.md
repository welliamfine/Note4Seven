# RC 交付与验收说明

## 本次范围

RC 在 Alpha 记录闭环和 Beta 多人关系闭环上完成 M6-M7 的客户端可交付能力。新增界面继续复用纸张材质、40% 白色毛玻璃、30px 背景模糊和现有固定底部操作规范。在线 Figma 当前无读取权限，未覆盖界面依据工作区本地原型、PRD V6.4 和 UI 规范补齐。

### 图片展示

- 默认当前模块与当前月，支持月份切换；
- 只展示 `active/locked` 正式记录，过滤待审批与拒绝内容；
- 日期倒序、同日按成员加入顺序；
- 贴纸双列预览，点击查看原图、备注、成员和日期；
- 可返回对应日期详情，退出成员按匿名身份展示。

### 提醒与模块设置

- 每名成员独立设置开关、时间和小程序内提醒；
- 到点、未打卡、模块正常、成员活跃时生成通知；
- 同用户同模块同日最多一次，单用户每次扫描最多三个模块；
- 创建者可输入模块名并二次确认删除，普通成员保留退出操作。

### 删除与回收

- 删除后模块进入 7 天 `pending_delete`，立即从首页移除并停止写入；
- 补卡审批、加入申请和待办被取消或终结，Token 失效，提醒暂停；
- 创建者可从“我的 → 模块回收站”恢复；
- 恢复不复活旧邀请、已取消审批和加入申请；
- 到期维护会永久清理模块关联记录、回应、审批、提醒、快照和回忆缓存，保留非内容审计。

### 回忆与导出

- 周概览六项使用正式记录、回应和快照计算；
- 日终快照保存历史成员集合，补卡通过后重新计算目标日；
- 月度卡按成员公平抽取最多 8 张，同一数据默认稳定复用；
- “换一组”更新抽取代次，成员素材充足时数量相差不超过 1；
- 支持模块/月选择并保持当前页面状态；
- 使用小程序 Canvas 生成 2×4 月度卡，主动请求相册保存权限；
- 导出内容不包含完整备注、审批信息和其他隐私字段。

### 我的与隐私

- 通知、隐私、回收站和退出入口完整；
- 隐私页展示版本、照片使用和访问边界；
- 账号删除申请采用独立二次确认和 7 天冷静期，可撤销。

## 自动验收

运行：

```powershell
npm run verify
```

检查内容包括 TypeScript、日期与动效测试、Alpha/Beta/RC 业务契约、页面构建、JSON 和静态资源引用。RC 契约覆盖图片过滤与排序、提醒每日去重、删除级联、恢复、到期清理、月度卡稳定公平和账号删除冷静期。

## 正式环境边界

以下能力已保留接口、状态和降级逻辑，但不能在缺少 AppID 或后端的工作区中伪装为生产完成：

- 微信订阅消息：当前可配置个人提醒并生成小程序内通知；正式模板 ID 配置后才能发起微信授权与发送。
- 定时任务：本地在应用启动、通知读取和回忆统计时执行维护；生产环境需要每分钟提醒任务、每日 00:05 快照任务和永久删除任务。
- 图片和账号清理：本地清理数据引用；私有对象存储文件和账号合规处理必须由服务端编排。
- 并发与审计：本地状态机已有重复操作守卫；生产环境仍需事务、行锁、Outbox、告警和人工重放。

M8 的生产域名、监控、压测、安全测试、灰度和微信审核属于发布门禁，不在无生产凭据的本地 RC 中冒充完成。
