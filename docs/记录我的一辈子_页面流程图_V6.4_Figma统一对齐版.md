# 《记录我的一辈子》页面流程图

版本：V6.4（Figma最高优先级统一对齐版；纯照片打卡、无模块头像）

## 对齐原则

- Figma已展示界面的布局、可见文案、弹层形态和跳转优先于历史文档；
- Figma未展示的功能继续按PRD实现；
- 示例人物、日期和统计数字不硬编码；
- 邀请与成员管理中的叶子为固定装饰，不是模块头像或接口字段；
- 打卡新增和编辑统一使用高位底部编辑面板；
- 备注字段在接口与数据中统一命名为 `remark`。

## 二、底部Tab与页面层级流程

    flowchart LR
        H[首页] <--> R[回忆]
        R <--> F[发现]
        F <--> M[我的]
        M <--> H

底部Tab包含：

- 首页；
- 回忆；
- 发现；
- 我的。

切换Tab时返回对应一级页面，并保留该Tab最近一次滚动位置和非敏感筛选状态。

### 页面与弹层层级

    flowchart TD
        A[当前页面] --> B{触发类型}
        B -- 普通页面跳转 --> C[压入页面栈]
        C --> C1[点击返回或系统返回]
        C1 --> A

        B -- 底部弹层 --> D[当前页面保持原位置]
        D --> E[背景轻遮罩或模糊]
        E --> F[弹层自底部上推]

        F --> G{关闭方式}
        G -- 关闭按钮 --> H[弹层下沉]
        G -- 下滑 --> H
        G -- 点击遮罩 --> H
        G -- 系统返回 --> H
        H --> A

使用底部弹层的场景：

- 创建记录模块；
- 日期详情；
- 成员操作；
- 轻量模块或月份选择。

存在未保存内容时，关闭前必须确认“继续编辑 / 放弃”。转让创建者、移出模块等动作先关闭操作面板，再展示二次确认，避免多层业务弹层叠加。

### 首页模块分组

    flowchart TD
        A[有效模块] --> B{当前用户是否置顶}
        B -- 是 --> C[置顶模块]
        B -- 否 --> D[普通模块]
        C --> E[组内按lastActivityAt倒序]
        D --> E
        E --> F[同一模块只展示一次]

### 首页模块卡片状态

    flowchart TD
        A[模块卡片] --> B[记录名称]
        A --> C[活跃成员头像]
        A --> D{今日是否有正式记录}

        D -- 否 --> E[贴纸区域留白]
        D -- 是 --> F[生成todayPreviewItems]
        F --> G[按首次正式生效时间升序]

### 首页当日贴纸新增流程

    flowchart TD
        A[某成员完成今日记录] --> B[记录正式生效]
        B --> C[刷新模块todayPreviewItems]
        C --> D[与页面旧列表按recordId对比]
        D --> E{是否为新增记录}

        E -- 是 --> F[旧贴纸向左移动一个展示步长]
        F --> G[新贴纸从右侧进入]
        G --> H[新贴纸位于最右且z-index最高]

        E -- 编辑替换 --> I[原位置贴纸淡入更新]
        E -- 删除 --> J[目标贴纸淡出]
        J --> K[剩余贴纸按时间顺序向右收拢]

示例：

    A B C D + E
    → B C D E

正常人数上限为4，前端仍必须执行“最多取最新4项”。

### 编辑面板关闭

    flowchart TD
        A[编辑面板打开] --> B{关闭方式}
        B -- X按钮 --> C{是否有未保存修改}
        B -- 下滑 --> C
        B -- 点击遮罩 --> C
        B -- 系统返回 --> C

## 二十四、Figma示例数据处理规则

- Frame名称、示例人数和画面中的成员头像数量不一致时，不按示例文字硬编码，以接口返回的活跃成员数量和 `joinSequence` 为准；
- 底部主按钮由本人当天记录状态决定：无记录为“记录今日”，有正式记录为“编辑今日”；
- 未来日期也打开日期详情底部面板，但面板只读且没有底部主按钮；
- 叶子装饰由前端设计资源提供，不进入创建、编辑、接口、数据库、状态机或埋点业务属性。
