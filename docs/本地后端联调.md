# 本地后端联调

本模式让微信开发者工具中的小程序连接电脑上的真实 Express 后端和 MySQL，适合快速调试模块、记录、成员、审批、权限和数据库事务。

## 启动

在仓库根目录运行：

```powershell
npm run dev:local-backend
```

该命令会自动完成：

1. 启动 Docker 中的 MySQL 5.7，映射到本机 `3307` 端口；
2. 首次运行时创建 `server/.env.local`；
3. 自动执行数据库迁移；
4. 在 `http://127.0.0.1:8080` 启动后端并监听代码变化；
5. 持续构建 `dev-server` 模式的小程序到 `dist/`。

微信开发者工具继续打开仓库根目录即可。项目配置已经关闭合法域名校验。

## 数据和图片

- MySQL 数据保存在 Docker volume `note_my_life_mysql_dev` 中；
- 本地图片保存在 `server/.local-storage/` 中；
- 停止监听不会清除数据库和图片；
- 停止数据库使用 `npm run local:down`；
- `docker compose down` 不会删除 volume，除非显式增加 `-v`。

## 开发身份

本地后端默认使用测试身份 `dev-user-1`，不会请求真实 OpenID。需要模拟另一位成员时，在微信开发者工具控制台执行：

```javascript
wx.setStorageSync('record_life_dev_openid', 'dev-user-2')
wx.removeStorageSync('record_life_access_token_dev')
```

重新编译后即以第二个本地用户登录。

## 与生产环境的差异

本地模式仍使用真实数据库表、事务、唯一约束、权限判断和业务接口。以下能力会使用开发替代实现，最终必须部署到云端验证：

- 微信云托管注入的 OpenID；
- 微信文字和图片内容安全；
- 腾讯云对象存储与数据万象抠图；
- 订阅消息；
- 图片审核回调；
- 正式小程序码。

生产构建仍使用：

```powershell
npm run build:production
```

`dev-server` 模式不会改变生产配置或生产数据库。
